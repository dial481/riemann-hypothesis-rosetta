## Reproduce

From the repository root, the frozen identifier index reproduces the joins even after the live catalogue changes. The raw HTML snapshot is stored locally under `inputs/odesky/`. The extraction reads the Lean and File fields, the entry link and its enclosing section link. The committed index preserves the validated identifiers and file citations. The manifest hashes decompressed contents for gzip artifacts and file contents for text. Run from the stacked checkout with the original metrics and upstream kernel file mask in place.

```bash
set -eu
export LC_ALL=C
mkdir -p inputs/kernel inputs/odesky
curl -fsSL --retry 3 https://github.com/james-shore/rh-proof-dependencies/releases/download/v0.2.1/decls.csv.gz -o inputs/kernel/decls.csv.gz
echo 'bdfeae289f2db8b279816439049f26ba69ec993af2bab3b30d53340fe02493b9  inputs/kernel/decls.csv.gz' | sha256sum -c -
.venv/bin/python analysis/odesky_coverage.py --index results/phase-2/odesky-index.tsv.gz --owners inputs/kernel/decls.csv.gz --out inputs/replayed-coverage
cmp results/phase-2/odesky-sha256.json inputs/replayed-coverage/odesky-sha256.json
```

To re-extract the metadata with the captured HTML, run the following commands. To attempt a fresh retrieval without overwriting the snapshot, run `curl -fsSL --retry 3 https://andrewodesky.com/rh/index.html -o inputs/odesky/live-index.html` and pass `--html inputs/odesky/live-index.html` instead. The extractor checks the pinned digest.

```bash
set -eu
export LC_ALL=C
echo '2c57f0ee0c8d291a1595ab46e1a6a4c732c10b14ca15b46cd4f0431b20e8879e  inputs/odesky/index.html' | sha256sum -c -
.venv/bin/python analysis/odesky_coverage.py --html inputs/odesky/index.html --owners inputs/kernel/decls.csv.gz --out inputs/reextracted-coverage
cmp results/phase-2/odesky-sha256.json inputs/reextracted-coverage/odesky-sha256.json
```
