## Declaration resolver correction

Lean’s `_root_.` prefix explicitly selects the root namespace. The first resolver stripped the prefix and searched open and enclosing namespaces. We discovered the error by checking every retained explicitly rooted token against its resolved source name. In the first freeze three of 11,986 such witnesses failed. The corrected run uses the exact rooted spelling, including when the final name is short. All 11,984 explicitly rooted witnesses in the corrected trace pass. The published consistency check now tests this condition over the entire trace.

## Graph and reproducibility checks

- Checked the in-degree and out-degree of all 184,307 vertices. For all 183,747 vertices reachable from Main, a separate DAG algorithm computed each immediate dominator as the common ancestor of direct predecessors in the growing dominator tree. It matched every parent, full and project-only cut, shortest and longest distance from Main, and height to a leaf. Main has no immediate dominator.
- Checked PageRank against its fixed-point equation, including dangling modules. Its L1 residual was $7.8\times10^{-8}$, below the stopping tolerance for this graph. Recomputing the score from the stored PageRank and independently counted cuts and degrees reproduced the import rank of every one of the 175,187 project modules. The project-community membership totals also matched. [Audit implementation](../../analysis/audit_graph.py)
- Rechecked the pinned headers in every source file, the three longest paths, the five largest cuts by direct deletion and all 200 source trails. Rendered the SVG to verify the labels and direction of the family-level import map. [Consistency check](../../analysis/check.py) · [Import map](../import-map.svg)
- Fixed the manifest builder and verifier to require the exact 20 generated independent artifacts. Previously an unrelated top-level file such as `NOTICE.md` could enter a newly generated manifest, and a shortened manifest could pass verification. The reader notice has its own history.
- Fixed external comparison downloads so a truncated cache file can be replaced on a fetch-enabled retry. A replacement is installed only after the expected digest matches. Tested valid cached reads, damaged-cache recovery, digest failure and rejection of an empty manifest. [Downloader](../../analysis/compare.py)

A fresh run in an empty output directory rebuilt the two input Git trees and all 20 independent artifacts. Its manifest and all 20 SHA-256 hashes matched. The post-freeze comparison then reproduced its seven generated files byte for byte.

From the repository root after reproducing the data, run the additional graph audit with `ROSETTA_RESULTS=inputs/reproduced .venv/bin/python analysis/audit_graph.py`.
